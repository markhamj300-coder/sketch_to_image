# sketch_to_image

The [sketch_image_pipeline.ipynb] shows the main results and code for this project. All the results can be viewed in github but if you want to run the code click on the open in Colab button at the top of the notebook and run all in Colab. Ensure a GPU is enabled.

[app.py] implements a user interface where sketches can be uploaded and images produced. To run the app open the [run_app.ipynb] in colab, enable a gpu and run all.
