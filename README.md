

# sketch_to_image

The [sketch_to_image_pipeline.ipynb](sketch_to_image_pipeline.ipynb) shows the main results and code for this project. All the results can be viewed in the notebook. To run the code click on the "Open in Colab" button at the top of the notebook, enable a GPU and run all.

[app.py](app.py) implements a user interface where sketches can be uploaded and images produced. To run the app open the [run_app.ipynb](run_app.ipynb) in colab, enable a gpu and run all.

I made a short video showing the UI: [Watch the UI demo](https://youtu.be/UndZBXL82uQ?si=KXMppU1bAhM0r-y4).

Finally the full report can be viewed [here](report.pdf).
